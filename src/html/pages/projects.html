Projects

Research activities I have undertaken to date, from industrial fatigue modeling to finite element and flow solvers built from scratch.

01

Continuum damage mechanics based fatigue initiation prediction model

  • Abaqus user subroutines
  • Fatigue
  • Damage mechanics
  • Developing Abaqus user subroutines for fatigue damage models of ductile materials with a cycle-jump algorithm to simulate the fatigue lifecycle of coupons and aircraft assemblies, with correlation to test data.
02

Flutter in functionally graded conical shell under follower force

  • Dynamic stability
  • Functionally graded materials
  • Shells
  • Studied the dynamic instability of an FGM truncated conical shell under follower force.
  • Published in Applied Mathematical Modelling and Archive of Applied Mechanics.
03

Investigation of snap-through phenomenon in thin shallow arch using corotational finite element formulation

  • MATLAB
  • Corotational FEM
  • Geometric nonlinearity
  • Developed FE code for corotational beam and truss formulations in MATLAB.
  • Studied the load–deflection behavior of a thin shallow arch with mid-span point load and compared results with existing literature.
04

Static analysis of portal frame by flexibility based beam-column element

  • MATLAB
  • OpenSees
  • Fiber discretization
  • Developed FE code in MATLAB for fiber discretization of a flexibility-based element and validated it with OpenSees.
  • Studied the behaviour of a one-storey portal frame by load- and displacement-controlled static analysis.
05

Plane strain problem – analysis of cantilever retaining wall using CST element

  • MATLAB
  • FEM
  • Plane strain
  • Developed FE code for the CST (Constant Strain Triangle) element in MATLAB.
  • Studied the behaviour of a cantilever retaining wall using the developed code and validated outputs with theoretical results.
06

Investigating nonlinear fluid–structure interaction dynamics using inviscid flow solvers

  • Vortex methods
  • Fluid–structure interaction
  • CFD
  • Developed a solver for the low-fidelity LVM (Lumped Vortex Method) to simulate fluid flow past a flat plate.
  • Developed a solver for the UVLM (Unsteady Vortex Lattice Method) to simulate fluid flow past a thin airfoil.
  • Led to a conference paper at CNSD-2016.
07

An introduction to structural dynamics, nonlinear dynamics, wind tunnel and a study on the Lorenz system

  • Nonlinear dynamics
  • Chaos
  • Implemented the modified Gram–Schmidt decomposition method to find Lyapunov exponents of the Lorenz system.
  • Developed a script for finding Poincaré maps of the Lorenz and Rössler systems.
